1. 简介

MyNext（“应用”或“我们”）致力于保护你的隐私。本隐私政策说明我们如何收集、使用、保护和共享你在使用 MyNext 应用时提供的信息。

2. 我们收集的信息

2.1 用户主动提供的信息

  • 账户信息：通过 Apple 登录时创建的 Apple ID 相关信息。
  • 愿望清单数据：你创建的愿望项目、行动计划、目标年龄等内容。
  • 进度和完成记录：标记任务完成状态、完成时间、备注等。
  • 提醒设置：你设置的提醒频率、时间和方式。

2.2 自动收集的信息

  • 设备信息：设备型号、操作系统版本、应用版本。
  • 使用统计：应用功能使用频率，仅用于改进产品体验。
  • 错误日志：应用崩溃或错误信息，用于帮助我们修复问题。
  • iCloud 数据：通过 CloudKit 同步的用户数据。

2.3 我们不收集的信息

  • 不收集你的位置数据。
  • 不收集你的联系人列表。
  • 不收集你的照片库。
  • 不收集你的个人身份识别信息，除非通过 Apple 登录产生的必要账户信息。
  • 不收集用于广告追踪的 IDFA。

3. 信息的使用目的

我们使用收集的信息用于以下目的：

3.1 应用核心功能

  • 创建和管理你的愿望清单。
  • 同步数据到你的 iCloud 账户。
  • 发送提醒通知。
  • 保存你的进度和完成记录。

3.2 产品改进

  • 分析用户行为模式，了解哪些功能最受欢迎。
  • 统计功能使用频率，优化用户界面。
  • 收集错误信息，及时修复应用问题。

3.3 AI 功能支持

  • 灵感推荐：根据你的愿望类别推荐灵感图片，可能使用第三方图片服务，例如 Unsplash 或 Pexels。
  • AI 助手：如用户启用 AI 生成功能，使用 Azure OpenAI API 生成行动建议。相关处理遵循微软隐私政策，详见 Azure 隐私声明。
  • 自动续期：重复任务完成后自动创建下一期任务。

3.4 法律和安全

  • 遵守法律要求和政府要求。
  • 保护我们的合法权利和用户安全。

4. 数据存储和安全

4.1 数据存储位置

  • 本地存储：应用数据首先保存在你的设备上，使用 SwiftData。
  • iCloud 存储：通过 CloudKit 加密同步到你的 iCloud 私有数据库。
  • Apple 服务器：iCloud 数据由 Apple 托管，位置取决于你的账户地区。

4.2 数据加密

  • 所有传输中的数据使用 HTTPS 加密。
  • iCloud 数据使用 Apple CloudKit 的端到端加密。
  • 本地数据使用 iOS 文件系统加密。

4.3 数据安全措施

  • 不将明文密钥保存在应用中。
  • 所有 API 调用使用安全的 HTTPS 连接。
  • 应用不存储你的 Apple ID 密码。
  • 定期更新依赖库以修复安全漏洞。

5. 第三方服务

5.1 CloudKit（Apple）

  • 用于跨设备数据同步。
  • 隐私政策：https://www.apple.com/privacy/
  • 数据完全由你的 iCloud 账户控制。

5.2 Azure OpenAI API（Microsoft）

  • 仅当你主动启用 AI 生成功能时使用。
  • 用于生成愿望建议和行动计划。
  • 隐私政策：https://privacy.microsoft.com/
  • 你可以随时禁用此功能。

5.3 灵感图片 API

  • 可配置为 Unsplash / Pexels 等图片服务。
  • 仅根据愿望类别查询公开图片，不传送个人数据。

5.4 通知服务（Apple）

  • 使用 Apple Push Notification Service（APNs）。
  • 仅用于发送你选择的提醒通知。
  • Apple 隐私政策：https://www.apple.com/privacy/

6. 数据共享

6.1 我们不会共享给以下主体

  • 广告公司。
  • 数据经纪商。
  • 第三方营销公司。

6.2 我们可能共享给

  • 信任的第三方服务提供商，例如上文列举的 Apple、Microsoft 或图片服务。
  • 法律要求或执法部门依法要求的情形。
  • 为保护用户和公众安全而有必要的情形。

7. 账户删除与数据删除

7.1 删除你的账户和数据

你可以随时在应用中删除你的账户。

操作路径：设置 → 账户管理 → 删除账户与数据

  • 应用本地数据立即删除。
  • iCloud 中的数据在 30 天内清除。
  • 已删除的数据无法恢复。

7.2 撤销 Apple 登录授权

删除应用账户后，如需撤销对 MyNext 的 Apple 登录授权，可按以下步骤操作：

  1. 访问 https://appleid.apple.com。
  2. 登录你的 Apple 账户。
  3. 在“应用和网站”部分找到 MyNext。
  4. 点击“停用”或“移除”。

8. 儿童隐私保护

MyNext 面向 13 岁及以上的用户。我们不会有意收集 13 岁以下儿童的个人信息。如果我们发现收集了儿童信息，我们将立即删除该数据。

9. 用户权利

9.1 欧洲用户（GDPR）

  • 访问你的个人数据。
  • 要求更正或删除数据。
  • 限制数据处理。
  • 数据可携带性。
  • 撤销同意。

9.2 加州用户（CCPA）

  • 了解我们收集的个人信息。
  • 删除你的个人信息。
  • 选择不出售你的个人信息。

10. Cookie 和追踪技术

MyNext 应用不使用 Cookie 或类似追踪技术。

如未来存在相关网站页面，网站端可能会使用 Cookie 改进用户体验，具体以当时网站隐私政策为准。

13. 特定功能的隐私说明

13.1 通知系统

  • 提醒通知保存在你的设备上和 iCloud 中。
  • 通知内容，例如任务标题、时间，属于你的私密信息。
  • Apple 无法看到你的个人通知内容。

13.2 分享卡片功能

  • 生成的分享卡片是静态图片，不包含额外个人身份信息。
  • 卡片仅包含愿望标题、类别与完成状态等你主动展示的内容。
  • 分享时调用系统分享表单，由你自行决定分享对象。

13.3 离线功能

  • MyNext 大部分功能在离线状态下也能使用。
  • 离线编辑的数据会在重新联网后自动同步。
  • 未同步的数据会暂时保存在你的设备上。
